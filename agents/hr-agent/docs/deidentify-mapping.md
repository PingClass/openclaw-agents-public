# 去識別化假名對照表

> 對應課程單元 6（U6p7）。真實人事資料放進 workspace 前，先照這張表換掉。
> **本表本身含真名，不得放進 workspace 或 git。** 填好的版本存在 HR 自己的私人位置，這裡只留空白範本。

## 要換掉的八種資料

姓名、電話、Email、身分證字號、地址、客戶或廠商名稱、金額、內部代號。

## 怎麼換

- 用固定的假名對照表（王大明 → 員工 A），整份資料前後一致。
- 保留格式和結構，只換內容（電話仍是 10 碼、日期仍是日期）。
- 換完自己再檢查一遍；不確定的就不要放進去。
