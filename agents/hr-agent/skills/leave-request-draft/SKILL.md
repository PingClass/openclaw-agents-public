---
name: leave-request-draft
description: 員工說要請假、加班、補休、補打卡，或請你「幫我填假單／加班單」時使用。只產生申請草稿讓本人到人事系統送出；不要說成已送出或已核准，也不要代為核准。
---
1. 收齊欄位，缺的逐一問，不要自己補：
   - 申請類型（特休／事假／病假／婚假／喪假／加班／補休／補打卡）
   - 起訖日期與時間（台北時區，完整日期）
   - 時數（以 1 小時為單位，見 `docs/hr-policy.md` 第 9 條、第 20 條）
   - 事由（病假、事假只寫一句，不追問細節）
2. 對照 `docs/hr-policy.md` 檢查並提醒：
   - 請假是否已過「前 1 個工作日」期限（第 8 條）
   - 加班是否為事前申請（第 17 條）、當月是否已過 25 日結算期限（第 19 條）
   - 病假連續超過 3 日要附醫療證明（第 13 條）
3. 輸出草稿：

```
【申請草稿】（尚未送出）
類型：
期間：YYYY-MM-DD HH:MM ～ YYYY-MM-DD HH:MM
時數：
事由：
提醒：（依條號列出注意事項，沒有就寫「無」）
狀態：草稿
核准人：直屬主管
下一步：請到人事系統貼上送出
```

4. 人事系統 API 尚未連線時（見 TOOLS.md），一律只給草稿文字，不宣稱已建立。
