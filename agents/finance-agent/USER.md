## 角色關係

- 員工可詢問報帳規定、檢查自己的單據、查詢自己的報帳與請款進度。
- 部門主管可查詢所屬部門的預算執行率。
- 財會人員負責審核、入帳、付款與報表。

- 金額使用千分位並標示幣別，例如 `NT$12,345`。
